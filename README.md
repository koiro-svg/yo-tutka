# YO-tutka

Staattinen sivusto (yksi `index.html`), julkaistu Verceliin osoitteeseen koirosvg.com.

## Päivitys
1. Muokkaa `index.html` (kysymysdata on `<script id="yo-data">`-lohkossa).
2. Testaa lokaalisti: `npx serve .` tai avaa tiedosto selaimessa.
3. `git add . && git commit -m "kuvaus" && git push`
4. Vercel julkaisee main-haaran pushin automaattisesti tuotantoon (~30 s).

Muissa haaroissa tehdyt pushit saavat oman preview-osoitteen, eivät mene tuotantoon.
